# Electricity Bill Calculator

A python program that calculates your electricity bill

## How to Run
1. Open 'electricity_calculator (1).py'
2. Run the program
3. Enter the required inputs

# Inputs needed
- Name
- Previous meter reading
- Current meter reading

## Sample output
Enter customer name: Gaib
Enter previous meter reading: 16
Enter Current meter reading: 21

Electricity Consumption: 5 kWh
Total bill: 64.5
