# Electricity Bill Calculator (V1 NO VALIDATION)

A python program that calculates your electricity bill

## How to Run
1. Open 'electricity_calculator (1).py'
2. Run the program
3. Enter the required inputs

# Inputs needed
- Name
- Previous meter reading
- Current meter reading

## Sample output
Enter customer name: Gaib
Enter previous meter reading: 16
Enter Current meter reading: 21
Customer: Gaib
Electricity Consumption: 5 kWh
Total bill: 64.5

# Electricity Bill Calculator (V2 WITH VALIDATION CODE)

A python program that calculates your electricity bill and detects whether your inputs are valid.

## How to Run
1. Open 'main.py'
2. Run the program
3. Enter the required inputs

# Inputs needed
- Name (not empty)
- Previous meter reading (a number at least zero)
- Current meter reading (a number at least the previous reading)

## Sample output
Enter customer name: Gaib
Enter previous meter reading: 16
Enter Current meter reading: 21
Customer: Gaib
Electricity Consumption: 5 kWh
Total bill: 64.5
